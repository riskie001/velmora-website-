# Velmora Model Hub

Static, mobile-first business website for Velmora Model Hub.

## Files
- `index.html` — complete website
- `assets/velmora-logo.png` — Velmora logo
- `assets/fredrick-ngugi.jpeg` — featured model
- `vercel.json` — optional Vercel configuration

## Add more models later
Open `index.html`, duplicate the featured model section inside `#models`, and change the image, name, specialty and social link.

## Add gallery media later
Replace the gallery placeholder cards in `#gallery` with `<img>` elements or linked video thumbnails.

## Deploy to Vercel
1. Create/sign in to a Vercel account.
2. Import this folder/repository as a project, or drag-and-drop the project folder in Vercel's dashboard.
3. Deploy. Vercel will provide a public `*.vercel.app` URL.
4. Put that URL in TikTok/Instagram bio.
5. Later, connect a custom domain such as `velmoramodelhub.com` if desired.

No build command is required; this is a static HTML site.
